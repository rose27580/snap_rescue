# 🚑 SnapRescue – Smart Breakdown Assistance Platform

SnapRescue is a full-stack web application that connects vehicle users experiencing breakdowns with nearby workshops in real-time.

The system allows users to request emergency assistance by submitting their location and vehicle details, while workshops receive and manage service requests efficiently.

---

## 🚀 Project Overview

SnapRescue streamlines roadside assistance through a structured workflow:

User → Submit Breakdown Request → System Processes → Workshop Receives Alert → Service Dispatched

It provides a seamless and responsive user experience using modern web technologies.

---

## ✨ Key Features

- 🔐 User Authentication System (Signup/Login)
- 📍 Location-based Breakdown Request
- 🛠 Workshop Dashboard
- 🧑‍💼 Role-based Access (Admin / User / Workshop)
- 📊 Request Tracking System
- 🔔 Real-time Alert Simulation
- 🎨 Clean and Responsive UI

---

## ▶️ How to Run Locally

1. Clone the repository  
   git clone https://github.com/rose27580/SnapRescue.git  

2. Navigate to project folder  
   cd SnapRescue  

3. Install dependencies  
   npm install  

4. Start the server  
   node app.js  

5. Open browser and visit  
   http://localhost:3000
